Liquid Glass Signer

基于 GitHub Actions 的液态玻璃签名工具 —— 在云端完成 IPA 重签名、源码自动构建签名与证书管理，全程无需本机安装 Xcode。

p12 + mobileprovision zsign / codesign GitHub Actions 驱动 iOS 26-27 设备支持
01三种签名能力

IPA 重签名

上传任意 IPA 直链 + 你的 p12 证书与描述文件，云端使用 zsign 快速重签名，自动处理扩展与插件，下载即装。

resign-ipa.yml

源码自动构建 + 签名

提供 iOS 工程仓库，macOS Runner 自动 xcodebuild Archive 并手动签名导出 IPA，支持 ad-hoc / development / enterprise / app-store。

build-sign.yml

证书管理

快速查看 p12 证书有效期、描述文件设备列表与 IPA 当前签名状态，签名前先体检，减少失败重试。

scripts/inspect.sh
02三步完成签名
1

准备材料

导出你的 .p12 证书（含密码）与 .mobileprovision 描述文件，将 IPA 上传到任意直链（如 Release 附件）。

2

运行工作流

在仓库 Actions 页选择 Liquid Glass 签名 - IPA 重签名，点击 Run workflow 并填入参数。

3

下载安装

运行完成后在 Artifacts 下载 signed-ipa，用任意安装工具装到 iOS 26 / 27 设备即可。

03签名控制台
点击选择证书 (.p12)证书仅在本机转换为 Base64，不会上传到网页服务器
点击选择描述文件 (.mobileprovision)同样仅在本机转换
由 GitHub Actions 驱动 · 证书与描述文件只属于你自己
